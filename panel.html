Falta conectar Supabase

El panel y la medición se activan cuando se pegan los datos de Supabase en analitica.js.

  1. En Supabase, abra SQL Editor, pegue el archivo analitica.sql y ejecútelo.
  2. En Authentication › Users › Add user, cree el usuario del propietario (marque Auto Confirm User).
  3. Ponga ese correo en la última línea de analitica.sql y ejecútela.
  4. En Project Settings › API Keys, copie la Project URL y la clave pública (anon o publishable) en analitica.js.

      Cómo usar el panel

      1. Elija el período arriba (Hoy, 7 días, 30 días…). Todos los números cambian a ese período.
      2. Cambie de categoría con las flechas amarillas de abajo. También sirven las flechas ← → del teclado y, en el celular, deslizar el dedo de lado.
      3. Toque el nombre del centro, abajo, para ver las 16 categorías y saltar a cualquiera. Las rayitas de arriba de las flechas muestran en cuál va.
      4. Pase el mouse o el dedo por un gráfico para ver el número exacto. Cada gráfico tiene «Ver como tabla».
      5. «Sube» y «Baja» comparan con el mismo número de días justo antes (por ejemplo, estos 30 días contra los 30 anteriores).
